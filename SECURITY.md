# Security

Do not report credentials, publisher conversations or exploitable vulnerabilities
in public issues. Use this repository's GitHub private vulnerability reporting
feature (Security → Report a vulnerability). If unavailable, do not post sensitive
details publicly; request a private reporting channel first.

Include affected versions, a minimal synthetic reproduction and the expected
boundary. Never include real API keys or customer data.

The current 0.1.x line supports test ads. SDK measurements are not a fraud verdict
or a guarantee of earnings. See the package documentation for the server/browser
credential boundary and permission responsibilities.
